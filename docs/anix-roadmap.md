# ANIX roadmap

## Before the first real pilot

- Pass the current source version's known seeds 664 and 654 in order, then targeted capabilities, a fresh mixed 20 (at least 19 completed, all integrity/recovery), and the gated 200-run campaign (at least 95% completion, all integrity/recovery/safety).
- Diagnose remaining failures from exact Lead traces; keep retry/stall budgets and model size unchanged.
- Validate evidence-grounded terminal synthesis separately from execution completion. The synthetic harness has not established general scientific accuracy.
- Close any newly reproducible BLOCKER/HIGH execution, authorization or recovery defect and retain negative regressions.

## After the first pilot

Evaluate real citation validity, Claim -> Evidence links, contradictions, unsupported findings, synthesis and uncertainty. Add missing domain/tool adapters according to actual research needs, with safe Human intervention and reproducible evaluation. Calibrate token/cost reporting against provider usage and record model revisions supplied by adapters.

## Before TUI

Stabilize application APIs, current status/trace projections, Human intervention contracts and source/artifact browser APIs. Build TUI only as a client of Core; no TUI was implemented in this iteration.

## Before a public release

Installer, onboarding, reproducible cross-platform builds, API migration policy, operational recovery guidance, independent security review, and research-quality evaluation. Preserve historical data and safe defaults.

## Future capabilities

Collaborator grants and multi-user access, branch budgets, a dedicated Batch scheduler, native Apple Foundation Models bridge and extended source/experiment adapters. These do not belong to the present hardening iteration.
